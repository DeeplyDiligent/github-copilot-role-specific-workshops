# Tic Tac Toe Game (Any Size)

This script demonstrates basic Python programming and includes a flexible Tic Tac Toe game that supports any square board size (n x n).

## Features
- Greets the user with a welcome message.
- Lets two players play Tic Tac Toe in the terminal.
- Supports any board size (3x3, 4x4, 5x5, etc.).
- Detects wins on rows, columns, and both diagonals.
- Detects draws.

## How to Use
1. Run the script:
   ```bash
   python 1a-basics.py
   ```
2. When prompted, enter `y` to play Tic Tac Toe.
3. Enter the desired board size (e.g., `3` for 3x3, `5` for 5x5).
4. Players take turns entering their moves as row and column numbers (e.g., `1 2` for row 1, column 2).
5. The game announces a winner or a draw.

## Example
```
Do you want to play Tic Tac Toe? (y/n): y
Enter board size (e.g. 3 for 3x3): 4
Tic Tac Toe Game! Player X goes first. Board size: 4x4
   ...gameplay...
```
